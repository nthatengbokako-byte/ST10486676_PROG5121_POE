# ST10486676_PROG5121_POE - POE Part 3


 Description
This is a Java console application for managing tasks.
Part 3 stores task data in arrays and displays a full report.

Features in Part 3
- Add tasks and store them in arrays
- Search for a task by Task Name
- Search for tasks by Developer
- Delete a task by Task Name
- Display a full report of all tasks
- Show tasks with status Done, To Do, and Doing

How to Run
1. Open the project in NetBeans 
2. Run the Main class
3. Follow the menu in the console
